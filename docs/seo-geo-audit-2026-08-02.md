# GetFRP SEO / GEO 体检（2026-08-02）

## 当前定位

GetFRP 最清晰、也最有差异化的定位不是“复材百科”，而是面向海外工程师与采购团队的英文 FRP 采购工作台：

> 产品规格定义 → 中国供应商能力匹配 → 标准/证据核对 → RFQ、QA 与出口交付。

这条定位已经落实到产品、供应商、标准、采购指南、工具与 RFQ 页面。应继续把“可验证的采购决策”作为主线，避免回到材料、论文、新闻、社区等栏目平均用力的门户式结构。

## 本次核查结论

| 维度 | 当前判断 | 证据 / 处理 |
| --- | --- | --- |
| 信息架构 | 主交易路径清晰；辅助栏目仍多 | 产品、供应商、标准、采购指南和 RFQ 已形成主路径；`community`、`trade`、`news`、`fibers`、`matrix` 已从 XML sitemap 移除，保留站内访问 |
| 产品 SEO | 8 个品类页内容和结构化数据较完整 | 规格、采购检查、FAQ、供应商关系齐备；本次补齐显式 `og:image` 和 Related Products |
| 供应商 SEO | 公开档案规模是主要长尾资产 | 构建结果包含约 470 个供应商/区域静态路径；显式产品关系继续用于 OfferCatalog，无关系时只显示“相关规格”链接，不冒充已验证能力 |
| 论文 SEO | 数量大、可索引质量小 | 3,730+ 英文标题中，大部分没有足够英文摘要；当前仅把达到摘要阈值的页面放入 sitemap，避免批量索引题录薄页 |
| URL 规范 | 旧论文 hash 是系统性问题 | 本次为所有论文生成英文标题 + 年份 canonical；旧 hash 和原始 ID 保留为永久重定向入口；公开 URL 全部控制在 100 字符内 |
| Sitemap | 过去的内容区边界混杂 | 本次新增独立 `data.xml`、`tools.xml`，并把 Wind Load、Buy America 与其他工具归入工具分区；新增 HTML `/sitemap` |
| 社交分享 | 品类页过去缺少缩略图 | 8 个品类页现在显式输出 960×600 主图及 alt、宽高信息 |
| GEO 可读性 | 基础较强 | 已有英文 `llms.txt` / `llms-full.txt`、WebSite/Organization/Product/FAQ/ScholarlyArticle JSON-LD、答案优先内容和 AI crawler 规则 |
| GEO 可信度 | 仍需补“谁审核、凭什么” | 采购指南多为 editorial desk；组织外部 `sameAs`、具名工程师作者、方法论和案例证据仍偏弱 |

## 搜索与抓取观察

- 当前搜索结果仍能看到已归档的 `/materials` 页面，说明搜索引擎尚未完全消化最近的产品架构重定向。应保留 301，并在新 sitemap 处理后观察 2–6 周，不应恢复旧页面。
- 论文库的数量不能直接等同于可索引资产。当前策略应是先丰富有英文摘要、工程结论、DOI/来源和相关产品链接的论文，再逐批进入 `papers.xml`。
- HTML sitemap 以核心页面、8 个产品、采购指南、技术参考、工具、区域页和全部公开供应商档案为主；论文与标准的大库通过可搜索 hub 进入，避免把一个用户页面做成数千条链接的抓取清单。

## GEO 设计优先级

1. **证据层**：为“verified / reviewed / export-ready”等状态建立公开方法页，明确证据类型、审核时间、适用产品与失效条件。
2. **作者与审阅实体**：把匿名 editorial desk 逐步替换为经授权的具名工程师/采购审核人，并提供稳定作者页、资历和审阅日期。
3. **可引用答案块**：在产品页增加短定义、典型范围、选型边界和“何时不适用”，让 AI 搜索可以直接抽取，同时链接标准与供应商证据。
4. **外部实体一致性**：建立可验证的公司资料页与行业账号后再补 Organization `sameAs`；不要为了 schema 完整而添加无法核验的链接。
5. **案例资产**：优先发布带规格、验收方法、问题与结果的匿名化项目案例，而不是继续扩张泛新闻/社区栏目。

## 建议监控

- 按 sitemap 子索引监控：已发现 URL、已抓取、已索引、被判重复、软 404、抓取耗时。
- 产品页 → 供应商页 → RFQ 的内部点击率与转化率。
- 供应商页返回产品页/标准页的点击率。
- 论文页中“有完整英文摘要 + 工程结论 + 来源”的覆盖率，而不是论文总数。
- Bing、Yandex 的 sitemap 处理状态与发现 URL 数；提交后分别记录首次抓取和错误反馈。

## 不建议做的事

- 不要为了 sitemap 数量把题录薄页、空 hub 或未维护栏目重新加入索引。
- 不要把推断出的供应商品类关系标记为 verified 或写入 OfferCatalog。
- 不要恢复中文 hreflang，也不要添加任何跨域或与其他站点的 hreflang 关系。
- 不要用大量无来源的“最佳、领先、已审核”表述换取关键词密度；这会同时削弱传统 SEO 与 AI 引用意愿。
